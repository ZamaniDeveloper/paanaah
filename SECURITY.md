# Security Policy

## Supported versions

Security fixes are applied to the latest code on the default branch.

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Report security concerns privately by email to **info@zamandev.ir** and include:

- A clear description of the issue
- Steps to reproduce it
- The affected component or endpoint
- The potential impact
- Any suggested remediation

Please avoid accessing, modifying, or deleting data that does not belong to you. Allow reasonable time for investigation and remediation before public disclosure.

## Security expectations

Production deployments should use strong secrets, HTTPS, restrictive CORS rules, upload validation, rate limiting, and an appropriate data-retention policy. Default development settings must not be used in production.
